Hermes Agent — 自分でスキルを育てるオープンソースエージェント

作成日2026-06-13|更新日2026-10-23

プロジェクト：NousResearch/hermes-agent · 作者：Nous Research · License：MIT
私はリポジトリを fork して Agent Loop、Skill Manager、Memory の実装を読みました。上流の開発には参加していません。

何を解決しようとしているか

Hermes Agent は Nous Research が2026年2月に公開したオープンソースの汎用エージェントです。単発のチャットボットとは異なり、長期運用に重点を置きます。以前のタスクを覚え、経験を再利用可能なスキルに変え、複数のメッセージプラットフォームから呼び出せます。

OpenClaw とは競合関係であり、後継ではありません。OpenClaw が先に注目を集め、Hermes は数週間後に自己改善と深いカスタマイズを強調して登場しました。

中核の仕組み

閉ループ学習

重要なのはフロー図ではなく、次の3点です。

  1. どんな条件で経験がスキルになるのか
  2. 新しいスキルが既存スキルと衝突しないようにするには
  3. 生成されたスキルの品質を誰が検証するのか

この3つに答えがないと、「自己進化」は「自分にバグを追加する」になりかねません。

メモリ

  • SQLite + FTS5 の全文検索
  • メモリ要約の自動生成
  • 定期的な「メモリ呼び戻し」
  • セッションをまたぐ継続性

メモリ層の最大のリスクは「忘れること」ではなく、誤って覚えることと覚えすぎることです。前者は後続の判断を汚染し、後者はコンテキストコストとノイズを増やします。

プラットフォームと自動化

Telegram、Discord、Slack、WhatsApp、CLI に対応。Cron スケジューラを内蔵し、日次レポート、ヘルスチェック、バックアップなどを無人で実行できます。

私の評価

方向性は正しいと思います。エージェントは一回限りの Q&A ではなく、蓄積するシステムであるべきです。ただし問題は「モデルができるか」から「どう管理するか」に移ります。スキルの権限、メモリの整理、コスト管理、ロールバックのほうが、デモ映像より重要です。
