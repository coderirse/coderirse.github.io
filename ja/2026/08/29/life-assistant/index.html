生活アシスタント — Tauri デスクトップアプリ

作成日2026-08-29|更新日2026-08-29

概要

「生活アシスタント」は自分専用の学習・生活管理デスクトップアプリで、Tauri + Rust + WebView2 で構築しています。すべてのデータはローカルのプロジェクトフォルダ内に保存され、リフレッシュ・終了・再起動しても失われません。GitHub モジュール以外は完全オフラインで、独立したバックアップ / リストア機能を備えています。

Tauri Rust SQLite 生産性

機能モジュール

  • ホームダッシュボード：今日の計画の進捗、クイックメモ、各モジュールのサマリー
  • 今日の計画：時刻順に当日のタスクを配置し、完了にチェック
  • 開発作業：タスク管理、作業時間の記録、週次統計
  • GitHub プロジェクト：自分のリポジトリ、アサインされた Issue、作成した PR を読み取り専用で表示（トークン必要、唯一のオンライン機能）
  • フィットネス：週間計画、トレーニング記録（種目 / セット / 回数 / 重量）、体重トレンドグラフ
  • 食事記録：3 食 + 間食の記録、よく食べる食材ライブラリ、当日のサマリー
  • ゲーム：ゲームライブラリ、プレイ時間の記録、週間合計
  • データと設定：バックアップ / リストア、ライト / ダーク / システム追従テーマ

エンジニアリング

  • データ層は独立した Rust crate（life-assistant-core）で、Tauri に依存せず cargo test でテスト可能
  • SQLite データベースとキャッシュはすべてプロジェクトの data/ ディレクトリに配置（C ドライブは使用しない）。バックアップはワンクリックで backups/ へ出力
  • GitHub トークンは Windows 資格情報マネージャー（keyring）に保存し、バックアップファイルには含まれない
  • レイヤーごとのテスト：フロントエンドの純粋ロジックは npm test、データ層は cargo test -p life-assistant-core

典型的な「自分のためのツール作り」プロジェクトです。すべてのモジュールが自分の実際の生活フローを中心に設計されているため、アカウント不要、トラッキングなし、完全オフラインを実現できます。
