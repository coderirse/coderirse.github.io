BaseConversion — Programmer’s Base Converter

Personal project · Maintained · Solo · Code public

A local, ad-free Android base converter with four linked bases, two’s complement and IEEE 754 bit patterns. The only network call checks for updates.

Net-USTB — One-Tap Campus Network Login

Personal project · Maintained · Solo · Code public

A third-party Android client for the USTB campus network (Dr.COM ePortal 4.x), with one-tap login/logout and AES-256-GCM credential storage.
