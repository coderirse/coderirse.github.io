# 2026-06-19 工作日志

## 修复中文页面字体渲染成日文字形的 bug

**根因：**
- `themes/butterfly/source/css/var.styl` 第 16 行：`$chineseFont` 根据编译时 `$language` 变量决定，多语言项目构建时部分页面会用 `Microsoft JhengHei` 而非 `Microsoft YaHei`。
- 更深层原因：默认字体栈缺少对 CJK fallback 顺序的显式控制，macOS/Windows 系统日文字体（Yu Gothic、Hiragino Kaku Gothic）在浏览器 fallback 链中优先级可能高于中文字体，导致中文汉字渲染成日文字形。

**修复方案：**
1. `source/css/custom.css` 头部新增 `html[lang="zh-CN"]` / `html[lang="ja"]` / `html[lang="en"]` 三段字体栈覆盖规则，强制把日文字体排到中文字体后面。
2. `source/js/lang-switcher.js` 中新增 `document.documentElement.setAttribute('lang', currentLang)` 确保客户端渲染时 `<html lang>` 与 URL 检测到的语言一致，让 CSS 字体选择器可靠生效。
3. 同时修复 `rewriteLinks()` 的几个小 bug：中文页面不再无效重写链接；`detectLang()` 改用正则支持无尾斜杠路径；`stripLang()` 改用正则避免截取长度硬编码。
