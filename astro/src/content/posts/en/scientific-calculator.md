## Overview

A feature-complete Android scientific calculator built with pure Kotlin + Jetpack Compose. Beyond standard scientific calculations, it integrates an equation solver and matrix calculator.

{% label Kotlin blue %} {% label Compose green %} {% label Material3 orange %}

### Three Modules
- **Scientific Calculator**: Trigonometry (DEG/RAD), logarithms, expression evaluation via Shunting-yard algorithm + recursive descent
- **Equation Solver**: Linear, quadratic (discriminant analysis), 2x2/3x3 systems via Cramer's rule
- **Matrix Calculator**: 2x2/3x3 add/sub/multiply, determinant, inverse (adjugate method), rank (Gaussian elimination)
