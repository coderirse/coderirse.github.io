ShowWe — 微信小程序社区平台

发表于2026-07-12|更新于2026-07-12|项目

项目概述

ShowWe 是一个基于微信云开发构建的全功能社区/社交小程序，v1.1.0。用户登录后可发布帖子（图片+文件附件）、评论点赞、私信聊天，拥有通知系统和个性化主页。

微信小程序 云开发 JavaScript

核心功能

  • 帖子系统：富文本 + 最多9张图片 + 5个文件附件，6种分类，自动提取 #标签#
  • 社交互动：评论/点赞（乐观 UI + 原子数据库操作）、浏览量去重追踪
  • 私信聊天：一对一文本+图片消息，未读计数红点徽章
  • 通知系统：点赞/评论通知，TabBar 红点汇总
  • 搜索：正则表达式全文搜索（不区分大小写）

技术亮点

  • 微信云数据库+云存储+云函数
  • 内存缓存（TTL 过期）+ 本地存储缓存实现秒开
  • 图片自动压缩（质量80%）+ 统一上传服务（支持重试）
  • 自定义组件：image-preview 画廊、load-more 状态指示器
