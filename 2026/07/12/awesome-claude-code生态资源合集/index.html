awesome-claude-code — 一张 Claude Code 生态地图

发表于2026-07-12|更新于2026-10-23|开源观察

项目：hesreallyhim/awesome-claude-code · 作者：hesreallyhim
本文是资源导读，我没有参与维护。

它是什么

awesome-claude-code 是一个社区维护的 Claude Code 资源列表，用经典的 Awesome List 格式整理工具、技能、插件、多智能体编排、安全、可观测性等 20 多个类别。

它的价值不是「收录得多」，而是做过筛选：主列表只保留维护者认为值得看的条目，历史条目被冻结在 README_ALTERNATIVES 目录里。

我会怎么用

  1. 先看 Start Here / Documentation，把官方能力边界弄清楚；
  2. 再按当前问题找 2–3 个工具，而不是把整个列表装一遍；
  3. 对每个工具看最近提交、Issue 响应和 License，Star 数只作参考。

提醒

这类列表很容易变成「链接农场」。真正有用的是你为了解决哪个问题去用它，而不是收藏了多少条。如果你只是刚开始用 Claude Code，先把官方文档和两三个高频工具用熟，比逛完整个列表更有效。
