名人名言 — 关于技术与创造

发表于2026-06-13|更新于2026-06-19|摘录
|浏览量:

关于编程之美

“Talk is cheap. Show me the code.”

— Linus Torvalds，Linux 与 Git 之父

“Any fool can write code that a computer can understand. Good programmers write code that humans can understand.”

— Martin Fowler，《重构》作者

“Programs must be written for people to read, and only incidentally for machines to execute.”

— Harold Abelson，《计算机程序的构造和解释》作者

“First, solve the problem. Then, write the code.”

— John Johnson

“The best way to predict the future is to invent it.”

— Alan Kay，面向对象编程先驱

关于技术创新

“Innovation distinguishes between a leader and a follower.”

— Steve Jobs，Apple 联合创始人

“The computer was born to solve problems that did not exist before.”

— Bill Gates，Microsoft 联合创始人

“Stay hungry, stay foolish.”

— Steve Jobs，2005 年斯坦福毕业演讲

“The only way to do great work is to love what you do.”

— Steve Jobs

“Simplicity is the ultimate sophistication.”

— Leonardo da Vinci

关于开放与协作

“Given enough eyeballs, all bugs are shallow.”

— Eric S. Raymond，《大教堂与集市》作者

“In real open source, you have the right to control your own destiny.”

— Linus Torvalds

“Alone we can do so little; together we can do so much.”

— Helen Keller

这些名言提醒我们，技术真正的力量不在于代码本身，而在于代码背后的人与思想。
