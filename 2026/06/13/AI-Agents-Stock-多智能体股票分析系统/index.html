AI Agents Stock — 多智能体股票分析系统

发表于2026-06-13|更新于2026-06-13|项目
|浏览量:

项目概述

AI Agents Stock 是一个创新的多智能体股票分析平台，通过模拟一支完整的证券分析师团队，为投资者提供全方位、多维度的股票投资分析决策支持。

核心理念：让多个专业化 AI Agent 像真正的分析师团队一样协作，从不同角度解读市场数据。

功能模块

单股深度分析（6 大 AI 智能体）

智能体 分析维度 核心能力
技术面 Agent K线形态、均线系统、MACD/RSI 趋势判断与买卖点识别
基本面 Agent 财报数据、估值指标 公司价值评估
资金流向 Agent 大单追踪、北向资金 主力动向监测
风险评估 Agent 波动率、最大回撤、VaR 量化风险度量
情绪分析 Agent 新闻舆情、社交媒体 市场情绪感知
新闻 Agent 公告解读、行业动态 事件驱动分析

智策板块 — 板块轮动分析

4 个 AI Agent 每日自动生成板块策略报告：

  • 板块轮动分析（行业趋势、资金轮动）
  • 宏观政策解读（货币政策、产业政策）
  • 资金流向监控（北向资金、主力资金）
  • 市场情绪感知（恐慌/贪婪指数）

智瞰龙虎 — 龙虎榜追踪

5 个 AI Agent 分析每日龙虎榜数据：

  • 游资席位识别与追踪
  • 机构席位动向分析
  • 短线交易机会挖掘
  • 热门板块与涨停逻辑分析

其他核心功能

  • 主力选股：机构资金流向筛选，3-5 只优质标的
  • 实时监控：价格预警 + 钉钉/飞书通知
  • MiniQMT 集成：量化交易策略执行
  • Docker 部署：一键启动，开箱即用

技术栈

primary danger info warning success primary
  • 前端：Streamlit 交互式界面
  • 数据源：AKShare、yfinance、Tushare、pywencai
  • AI 模型：支持 DeepSeek、Qwen、GPT-4o 等大模型
  • 数据分析：pandas、numpy、ta（技术分析指标）
  • 可视化：Plotly 交互式图表
  • 存储：SQLite (peewee ORM)
  • 部署：Docker + Docker Compose

设计思想

这个项目的核心在于 Agent 分工协作 的设计模式。单个 AI 的分析能力有限，但如果让 6 个分别专注于不同领域的 Agent 同时工作，再综合各方意见，就能产生远超单一视角的洞察力——就像真正的投资研究团队一样。

这种多 Agent 协作的架构不仅适用于金融分析，也可以迁移到其他需要多角度决策的领域。
