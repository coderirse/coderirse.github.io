## 概要

**Academic Research Skills (ARS)**は、Claude Codeのための専門学術研究ツールキットで、文献調査から論文出版までの完全な研究ワークフローを、編成可能なAIスキルパイプラインとしてパッケージ化しています。

{% note success %}
「ツールのためのツール」— AIが研究者をより良く支援するために、研究者を置き換えるのではありません。
{% endnote %}

## 4つのスキルパッケージ

### Deep Research — 深層研究

13の専門エージェントチーム、7つの作業モード：

| モード | 目的 |
|------|---------|
| 完全研究 | エンドツーエンド学術研究 |
| クイックブリーフ | 迅速な文献概要 |
| 文献レビュー | 体系的文献レビュー |
| 系統的レビュー | PRISMAプロトコル + メタ分析 |
| ファクトチェック | 主張の正確性検証 |
| ソクラテス式 | 対話型研究メンタリング |
| 論文レビュー | 投稿前原稿審査 |

### Academic Paper — 論文作成

12エージェントの作成パイプライン、10モード：

- 全文 / アウトライン / 抄録 / 文献レビュー生成
- 改訂・改訂コーチング
- 引用形式チェック
- 形式変換（LaTeX / DOCX / PDF）
- バイリンガル抄録（中/英）

{% label APA 7.0 blue %} {% label IEEE green %} {% label MLA pink %} {% label Chicago orange %} {% label Vancouver red %}

### Academic Paper Reviewer — 査読

5人の独立した査読者による多角的評価：

- **EIC（編集長）**：総合評価と判定
- **3人の査読者**：方法論、理論的貢献、実験設計
- **Devil's Advocate**：最も厳しい問題点を指摘

各査読者は専門分野の視点と0-100の評価基準を持ちます。

### Academic Pipeline — 完全パイプライン

10段階のエンドツーエンドワークフロー：

```
研究 → 執筆 → 整合性チェック → 査読 → 改訂 → 再査読 → 再改訂 → 最終チェック → 確定
```

各段階に**必須の品質ゲート**を設定。

## 主要な革新

### 反ハルシネーション検証

主張と原文の強制クロスチェックにより、AIの生成内容に根拠があることを保証します。

### スタイルキャリブレーション

対象ジャーナルや会議の執筆スタイルに自動適応。

### ソクラテス式メンタリング

直接答えを与えるのではなく、質問を通じて研究者の思考を導きます。

## プロジェクトの意義

学術執筆には極めて高い厳密性が求められますが、AIの「ハルシネーション」問題が最大の障壁です。ARSの核心的設計思想は**プロセスと検証でハルシネーションと戦うこと** — AIに代筆させるのではなく、AIを信頼できる学術協力者にすることです。
