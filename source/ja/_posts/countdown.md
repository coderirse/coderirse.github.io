## 概要

現在企画段階にあるカウントダウン / カウントアップ Android アプリです。プロダクトドキュメント（PRD v0.1）と技術設計は完成しましたが、コーディングはまだ始まっていません。設計プロセスを「書くこと = 設計すること」の実践として共有します。

**ひとことで**：大切な日を「スマホを開けば必ず目に入る場所」に置く——ホーム画面のウィジェットで、目標日まであと何日、または経過して何日かをいつでも確認できます。

### プロダクト思考
- **カレンダーではなく、感情のためのツール**：核心の価値はスケジュール管理ではなく、時間の距離をひと目で感じる「確信」と「儀式感」——付き合った日数、試験までのカウントダウン、出産からの日数、給料日 / 返済日
- **最小のコアパス**：初回起動で 3 ステップ以内に最初のイベントを追加し、ウィジェット設置をガイド。日常利用ではアプリを開く必要すらなく、ホーム / ロック画面のウィジェットを見るだけ
- **抑制**：課金なし、広告なし、アカウント不要、クラウド同期なし。まず自分用として作り、将来的に完全オープンソース化

### シナリオ駆動のイベントタイプ
- 試験カウントダウン（大学入試 / 英検 / 期末）——大きな数字 + 試験前リマインダー
- 記念日のカウントアップ（付き合った日数、出産からの日数）
- 平日カウントダウン（給料日 / 返済 / 締め切り）——ロック画面でも表示
- 習慣の継続記録（何日目か、連続記録とマイルストーン）

### 技術選定
設計ドキュメントではウィジェットの 3 つの実装ルートを比較し、**Jetpack Glance + Compose** をメインルートと結論付けました。Compose と同じ宣言的 DSL の考え方、Material You ダイナミックカラーへの自然な対応、将来的な Wear OS Tiles への API 転用が可能。複雑なインタラクションには従来型 AppWidgetProvider で補完します。データ層は Room + DataStore を計画し、ウィジェットの日次更新仕組みも検討済み。スケルトンは準備完了（Kotlin 2.2 + Compose BOM 2026.02、minSdk 35 / Android 15）。
