## はじめに

**Hermes Agent**は、Nous Researchが開発した次世代汎用AIエージェントです。従来の単発チャットボットとは異なり、Hermesは**閉ループ学習システム**を備え、完了したタスクから自律的にスキルを作成し、継続的に改善します。

{% note info %}
HermesはOpenClawの後継であり、アーキテクチャを全面的に刷新しています。
{% endnote %}

## コア機能

### 閉ループ学習

最大の革新 — 複雑なタスク完了後、自動的に経験を**再利用可能なスキル**に蒸留します：

```
タスク → 記録 → スキル作成 → 改良 → 永続化
  ↑                                    ↓
  └──── 将来のタスクで自動呼び出し ←────┘
```

### マルチプラットフォームゲートウェイ

HermesはCLIだけでなく、完全なクロスプラットフォームエージェントシステムです：

### 40以上の組み込みツール

ファイルI/O、ネットワークリクエスト、コード実行、データクエリ、API呼び出し — **MCP（Model Context Protocol）**で拡張可能。

### 永続的メモリ

- **SQLite + FTS5**全文検索
- 自動メモリ要約
- 定期的「メモリナッジ」機構
- セッションを超えた知識継続

### 無人自動化

組み込み**Cronスケジューラ**で日次レポート、システム健全性チェック、バックアップ、ニュース配信を自動実行。

## 考察

Hermesとの関わりを通じて、「エージェント」の本質を深く理解しました — 単純な入出力モデルではなく、**継続的に学習するシステム**です。真に強力なエージェントには、メモリ、スキル、自己進化能力が必要です。Hermesはその道を着実に歩んでいます。
