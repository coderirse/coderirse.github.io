## 概要

awesome-claude-code は、Claude Code のリソースを Awesome List 形式で整理したコミュニティ保守のリストです。ツール、スキル、プラグイン、マルチエージェント編成、セキュリティ、可観測性など20以上のカテゴリを扱います。

価値は「全部載っていること」ではなく、**選別されていること**にあります。メインリストは保守者が読む価値があると判断した項目だけを残し、古い項目は `README_ALTERNATIVES` に凍結されています。

## 私ならこう使う

1. まず Start Here / Documentation で公式の能力範囲を確認する
2. 今解きたい問題に対して2〜3個のツールを選ぶ。全部入りは入れない
3. 各ツールの最近のコミット、Issue 対応、License を見る。Star 数は参考程度にする

## 注意

こうしたリストは「リンク農場」になりがちです。大事なのは**どの問題を解決するために使うか**であり、何件保存したかではありません。Claude Code を始めたばかりなら、公式ドキュメントとよく使う2〜3個のツールを使い込むほうが、リスト全体を読むより効果的です。
