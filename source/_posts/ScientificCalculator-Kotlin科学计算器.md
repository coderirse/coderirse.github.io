## 项目概述

一款功能完整的 Android 科学计算器应用，使用纯 Kotlin + Jetpack Compose 开发。不仅支持标准科学计算，还集成了方程求解器和矩阵计算器。

{% label Kotlin blue %} {% label Compose green %} {% label Material3 orange %}

### 科学计算器

基础运算 + 三角函数（DEG/RAD 切换）+ 对数函数 + 平方根/绝对值。表达式求值引擎使用 Shunting-yard 算法 + 递归下降解析，支持可展开科学面板。

### 方程求解器

一元一次/二次方程（判别式分析）、二元一次/三元一次方程组（Cramer 法则 + 行列式展开）。

### 矩阵计算器

2x2/3x3 矩阵加减乘、转置、行列式、逆矩阵（伴随矩阵法）、秩（高斯消元）。
